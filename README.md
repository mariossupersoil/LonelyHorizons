# Lonely Horizons

Website for *Lonely Horizons: A Comprehensive Guide to Overcoming Loneliness and Social Isolation* by Samuel Knight.

The whole site is one file, `index.html`, with the cover and author photo embedded.

To add a "Buy the book" button, open `index.html`, find `var BUY_URL = "";` near the bottom and paste your store link between the quotes.
